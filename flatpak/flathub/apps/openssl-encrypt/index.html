📖 Description

OpenSSL Encrypt is a comprehensive encryption tool that provides military-grade security with cutting-edge post-quantum cryptography. Protect your files against both current and future quantum computing threats.

Perfect for individuals and organizations requiring the highest levels of data protection, including protection against future quantum computer attacks.

★ Features

🔐 Encryption Algorithms

  • AES-GCM (128/256-bit)
  • ChaCha20-Poly1305
  • XChaCha20-Poly1305
  • Fernet (AES-128-CBC)
  • AES-GCM-SIV
  • Threefish-512/1024 (native AEAD)

⚛ Post-Quantum Cryptography

  • ML-KEM (512/768/1024-bit)
  • HQC (128/192/256-bit)
  • MAYO (1/3/5 multivariate)
  • CROSS (128/192/256 code-based)
  • Kyber hybrid encryption
  • ML-DSA-65 signatures (Dilithium)
  • Quantum-resistant key exchange
  • Future-proof security

🔑 Key Derivation & Hashing

  • Argon2id, Scrypt, Balloon (memory-hard)
  • RandomX (CPU-optimized, anti-ASIC)
  • HKDF (RFC 5869)
  • SHA-2 / SHA-3 (224/256/384/512-bit), SHAKE
  • BLAKE3 (tree-based), BLAKE2b
  • Configurable rounds & salt generation

💻 User Interface

  • Modern GUI with dark/light themes
  • Command-line interface
  • Comprehensive debug mode with --debug flag
  • Drag & drop file support
  • Progress indicators
  • Batch processing

💳 Hardware Tokens (HSM)

  • YubiKey (HMAC-SHA1 challenge-response)
  • OnlyKey (cross-device fleet)
  • FIDO2 security keys
  • PIV / PKCS#11 smart cards
  • Hardware-derived pepper (never stored)

🔒 Security Features

  • Secure memory handling
  • Secure file deletion
  • Constant-time operations
  • Password strength validation
  • Environment variable support
  • Cascade multi-layer encryption
  • Streaming chunked encryption (constant-memory)
  • AEAD metadata binding (tamper detection)
  • Envelope encryption & fast credential rekey
  • ASCII armor output (paste-safe)
  • Source-code integrity (PGP-signed manifest)
  • Detached post-quantum signatures

📋 Recent Updates

1.4.7 STABLE RELEASE DOCS
Documentation and packaging release: refreshed the project page and README (rendered as the PyPI page) for the 1.4.6 feature set, including the key-derivation documentation, which now reflects format version 13 as the Independent XOR default. No functional, CLI, or on-disk format changes.
1.4.6 STABLE RELEASE FEATURE SECURITY
Major feature release. New PIV / PKCS#11 hardware-token backend (--hsm piv) for smart cards and tokens; source-code integrity verification via a PGP-signed manifest (verify-integrity); opt-in envelope encryption (--envelope) for low-cost credential rotation; detached post-quantum signatures (ML-DSA-65) via sign / verify-signature; and ASCII armor (encrypt --armor). Independent XOR key derivation now uses per-component domain-separated salts (format version 13) by default. Security fix: the optional, non-default sequential XOR mode could bypass the configured KDF cost in a single-KDF configuration — fixed and disclosed as GHSA-vxf9-vwp6-2w43 (CWE-916); default configurations were unaffected. Existing files remain decryptable.
1.4.5 STABLE RELEASE SECURITY
Security dependency update: urllib3 2.7.0, cryptography 46.0.7, pillow 12.2.0, idna 3.15 — fixes for CVE-2026-44431/44432, CVE-2026-39892, a PSD decoder out-of-bounds write, and an idna DoS. New CI check keeps flatpak dependency pins aligned with the package requirements.
1.4.4 STABLE RELEASE SECURITY
Security hardening release: authenticated keystore format, D-Bus polkit authorization, fail-closed PQC algorithm resolution, plugin sandbox enforcement, per-drive USB salts. New: cross-device YubiKey/OnlyKey HSM decryption, encrypt-CLI reconstruction from file metadata via the info action, Diceware passphrase generation, HSM-aware derive-password. Threefish extension builds on Python 3.14. Requires Python 3.11+.

Added RandomX support to independent XOR path. Progress bars for Argon2/RandomX in XOR mode. Dependency bumps: cryptography 46.0.6, requests 2.33.0, black 26.3.1, nltk 3.9.4.
