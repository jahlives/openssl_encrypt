📷 Tobi's Flatpak Repository

⚙ Setup Instructions

Add this repository to your system (both configurations point at the same repository; add the one matching the app you install):

flatpak remote-add --if-not-exists openssl-encrypt https://flatpak.rm-rf.ch/openssl-encrypt.flatpakrepo
flatpak remote-add --if-not-exists openssl-encrypt-gui https://flatpak.rm-rf.ch/openssl-encrypt-gui.flatpakrepo

📦 Available Applications

🔐 OpenSSL Encrypt (CLI)

OpenSSL Encrypt is a comprehensive command-line encryption tool that provides military-grade security with cutting-edge post-quantum cryptography. Protect your files against both current and future quantum computing threats.

This Flatpak ships the command-line tool with all its dependencies prebuilt (including liboqs for post-quantum cryptography) — no local build required.

📬 To report bugs or request features, send email to: issue+world-openssl-encrypt-2-issue-+gitlab@rm-rf.ch

📖 View Details
💻 Manual install: 
flatpak install openssl-encrypt com.opensslencrypt.OpenSSLEncrypt

🖥 OpenSSL Encrypt GUI (GUI + CLI)

The desktop GUI for OpenSSL Encrypt, bundled together with the full command-line tool. One install provides the graphical app and the exact CLI release it is paired with; the GUI adapts its features to the bundled CLI's capabilities.

🔄 Migration note: the combined GUI + CLI package was previously published under com.opensslencrypt.OpenSSLEncrypt. That ID is now the CLI-only app; if you used the combined package, reinstall the GUI once under the new ID below.

📬 To report bugs or request features, send email to: issue+world-openssl-encrypt-gui-28-issue-+gitlab@rm-rf.ch

flatpak install openssl-encrypt-gui com.opensslencrypt.OpenSSLEncryptGui
